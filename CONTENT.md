## Pages

**Sections:**
1. **Hero** — Animated expandable hero with rotating text and Aurora effect
2. **Philosophy** — "What Does The Cloud Mean?" explanation with Stars Canvas background

## SEO Configuration

- **Sitemap**: Auto-generated at `/sitemap.xml` via `app/sitemap.ts`
- **Robots.txt**: Configured at `/robots.txt` — allows all major crawlers
- **Open Graph**: Configured globally in `app/layout.tsx`
- **Twitter Cards**: `summary_large_image` format
- **Structured Data**: JSON-LD Organization schema in layout
- **Keywords**: cloud solutions, digital agency, web development, cloud infrastructure, digital transformation, business systems, web applications, AI tools
